# Перечень проверок «Аудит защиты»

Все проверки выполняются **только в режиме обнаружения** (без эксплуатации).
Уровень указан для максимальной опасности находки.

## 4. Методика скоринга

`Балл = max(0, 100 − Σ штрафов)`, где штраф: Критический = 25 × (CVSS/10 при наличии),
Высокий = 10, Средний = 4, Низкий = 1, Информация = 0.

- **80–100** — приемлемое состояние (остались только мелкие замечания);
- **50–79** — существенные проблемы, требуется план устранения;
- **0–49** — критическое состояние: немедленно устраняйте критические находки.
