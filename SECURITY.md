# Политика безопасности

## Область применения

Приложение «Аудит защиты» (Office Security Check) предназначено для **аудита
собственных** сетей и систем их владельцами или уполномоченными администраторами.

## Принципы

1. **Только обнаружение.** Приложение не содержит эксплуатирующих нагрузок
   (exploit-кодов), не изменяет конфигурацию проверяемых систем и не выполняет
   действий за пределами чтения ответов проверяемых служб.
2. **Добросовестное использование.** Сканирование чужих систем без разрешения
   владельца может нарушать законодательство (в т.ч. ст. 272 УК РФ и аналоги).
   Пользователь несёт полную ответственность за цели проверки.
3. **Приватность отчётов.** Отчёты содержат данные о вашей сети (IP-адреса, службы,
   уязвимости). Храните их в защищённом месте и не публикуйте без необходимости.
